站点总算搭起来了。这里以后放两类东西：拍的照片，和一些技术笔记。

## 为什么做这个站

主要是想把东西攒起来，而不是散在聊天记录和网盘里。自己的域名、自己的文件，内容随时能拿回来。

## 这篇是样例

以后写东西就这样写：一个 Markdown 文件，前面带几行元信息，正文随便写。

```bash
hugo new posts/某篇文章.md
hugo server -D
```

写完推上去，网站就更新了。

> 引用块也能用，长这样。
